# NoteNest (fictional)

NoteNest is a notes app for individuals and small teams.

## Platforms
iOS, Android, Windows and macOS desktop, and Web. Current version: 4.2.1.

## Features
- Rich-text notes, folders and tags (type # in a note to tag it)
- Full-text search
- Offline editing with sync when the device reconnects
- Attachments (images, PDFs)
- Reminders with push notifications
- Sharing a note with other people by email invite or link
- Export to PDF and Markdown
- Light and dark themes, code blocks

## Severity scale

| Level | Meaning | Example |
|---|---|---|
| S1 | Data loss, security problem, or crash that blocks many users | Notes deleted or overwritten |
| S2 | A major feature is broken for many users, or there is only an awkward workaround | Sharing fails for invitees |
| S3 | A feature is partly broken, or a clear workaround exists | A search quirk |
| S4 | Cosmetic or minor annoyance | A wrong suggestion in a list |

Feature requests and non-bugs have no severity (use null).
